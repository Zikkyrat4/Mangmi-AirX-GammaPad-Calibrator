# История версий

## v0.4.0-beta.1 — 2026-10-27

Первый экспериментальный публичный релиз для **Mangmi Air X / GammaOS Next 1.2**.

### Android-приложение
- Проверка доступа Root и состояния модуля.
- Поиск физического `AIR X Controller` (включая открытые дескрипторы GammaPad).
- Измерение центра и крайних положений обоих стиков.
- Сохранение `RANGE_CALIBRATION` с резервной копией и восстановлением.
- Работа с чувствительностью `ANALOGSENSITIVITY` без обязательного значения 0.
- Перезагрузка консоли для применения настроек.

### Magisk-модуль (v0.1.0)
- Экспериментальная коррекция диапазонов физических аналоговых осей.
- Проверки совместимости с исходным `gammapad`.
- Возможность отключения через Magisk или ADB.

### Известные ограничения
- Проверялось в рамках конкретной конфигурации консоли; широкая совместимость не подтверждена.
- APK имеет отладочную подпись: последующие версии, подписанные другим ключом, могут потребовать переустановки.
- Magisk ZIP содержит изменённый бинарный файл прошивки; условия его перераспространения требуют проверки.
- Автоматическая сборка через GitHub Actions пока не настроена.
