# GammaPad Calibrator — Mangmi Air X (experimental)

**Неофициальный экспериментальный проект** для Mangmi Air X под GammaOS Next v1.2.
Не относится к производителю приставки, GammaOS или Magisk. Работа на других прошивках **не подтверждена**.

## Состав

- `app/` — Android-приложение на Kotlin (версия v0.4).
- `magisk-module/` — скрипты Magisk и исходный код коррекции осей (`source/gpad.c`).
- `tools/` — PowerShell-инструменты для резервной калибровки и отката.
- `.github/workflows/build-debug-apk.yml` — экспериментальная CI-сборка APK.

В разделе **Releases** предполагаются **два установочных файла**:

1. `GammaPad-Calibrator-v0.4.apk` — Android-приложение (нужен Root).
2. `GammaPad-AirX-Fix-v0.1.0.zip` — Magisk-модуль для поддерживаемой прошивки.

⚠️ **Правовая оговорка:** исходный Magisk ZIP содержит модифицированный `gammapad`, полученный из прошивки устройства, и отдельную библиотеку `gpad.so`. Не публикуйте этот ZIP и оригинальный/модифицированный ELF в открытом репозитории или публичном релизе без подтверждения прав на распространение прошивки. В репозитории намеренно находятся только скрипты и исходный код собственной коррекции. Для публичного распространения предпочтителен инсталлятор, который патчит исходный бинарный файл непосредственно на устройстве пользователя после проверки SHA-256 (такой инсталлятор пока **не реализован**).

## Сборка APK

1. Откройте папку `repository/` как проект Android Studio, либо используйте уже настроенный Android Studio-проект, скопировав в него файлы из `app/`.
2. Android Gradle Plugin 8.13.2, Gradle 8.13, JDK 21 и Android SDK 35.
3. В Android Studio выберите **Build → Build APK(s)**, либо используйте установленный Gradle 8.13: `gradle :app:assembleDebug`.
4. APK: `app/build/outputs/apk/debug/app-debug.apk`.

Включённая GitHub Actions-сборка создаёт **debug APK**, который подписан временным отладочным ключом GitHub runner. Для постоянного публичного распространения используйте **стабильный собственный ключ подписи**. Иначе при обновлении Android может сообщить о несовместимой подписи.

## Установка и применение

- ZIP Magisk-модуля устанавливается через **Magisk → Modules → Install from storage**, затем перезагрузка.
- APK устанавливается как обычное Android-приложение и получает Root-доступ через Magisk.
- Перед сохранением калибровки приложение делает резервную копию `RANGE_CALIBRATION`. Штатный `CALIBRATION_DATA` не изменяется.
- Для отключения модуля через ADB: `adb shell su -c "touch /data/adb/modules/gammapad_airx_fix/disable"`, затем `adb reboot`.

**Важно:** модуль строго проверяет версию ROM, ARM64, имя контроллера, существование конфигурационных файлов и SHA-256 исходного GammaPad. Не устанавливать на другие устройства. Исходный ELF SHA-256: `55d1bb0e0ccd1609cc3906d3a0cbf615d6c279f003817ffe8a3fd947c1a80b23`.
