# Безопасность

**GammaPad Calibrator — экспериментальное Root-приложение для Mangmi Air X.**

- Проверяйте соответствие устройства и прошивки перед установкой Magisk-модуля.
- Сохраняйте доступ к ADB для восстановления; изменение GammaPad может нарушить ввод.
- Не передавайте APK или Magisk ZIP как универсальное решение для других устройств.
- Используйте резервные копии `RANGE_CALIBRATION`.
- Не публикуйте в Issues свои пароли, ключи подписи или токены.

Для отключения Magisk-модуля (если доступен Root ADB):

```sh
adb shell su -c 'touch /data/adb/modules/gammapad_airx_fix/disable'
adb reboot
```

Если обнаружили проблему безопасности, создайте GitHub Issue без публикации эксплойтов, ключей или приватных данных. Для чувствительных сведений используйте приватный канал связи с владельцем репозитория, если такой канал будет настроен.
